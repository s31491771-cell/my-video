# বাংলা ফাইন্যান্স ভিডিও — পেই ইওরসেলফ ফার্স্ট

৮ মিনিট ৫২ সেকেন্ডের বাংলা ভয়েসওভার ও ১৯৫-কিউ SRT থেকে তৈরি 2D ভেক্টর
এক্সপ্লেইনার। ফ্রেম: **1920×1080 (16:9)**, **30 fps**, H.264 MP4 + AAC।
ভিডিওতে কোনো সাবটাইটেল বার্ন করা নেই — SRT শুধু টাইমিং রেফারেন্স।

## এই ফোল্ডারে কী আছে

```text
src/                 Remotion সোর্স (৭৫টি দৃশ্য, ১৬টি টেমপ্লেট)
src/story.ts         SRT থেকে তৈরি দৃশ্য-টাইমলাইন (cue → frame)
src/timing.ts        মোট ফ্রেম + ১৬৪টি SFX কিউ
public/audio/        মূল ভয়েসওভার + ৯টি কোড-জেনারেটেড SFX
public/fonts/        Noto Sans Bengali (OFL)
assets/              মূল অডিও, ১৯৫-কিউ SRT, SFX কপি, ফন্ট লাইসেন্স
scene-plan.json      দৃশ্য পরিকল্পনা, সংলাপ ও SFX টাইমিং
manifest.json        রেন্ডার সেটিংস ও সোর্স তালিকা
job_state.json       কাজের অবস্থা (resume-এর জন্য)
scripts/             SRT→টাইমলাইন বিল্ডার, SFX জেনারেটর, QC, প্যাকেজার
```

## রেন্ডার করার নিয়ম

ফোনে (Termux) রেন্ডারধরা হয় না — Chromium ও ডিস্ক দরকার। ক্লাউড মেশিনে:

```bash
npm install
npm run render        # out/final-video.mp4
```

শুধু প্রিভিউ দেখতে: `npm run studio`।

## GitHub Actions দিয়ে রেন্ডার (কোনো কম্পিউটার ছাড়াই)

রিপোজিটরি: `s31491771-cell/my-video`, ব্র্যাঞ্চ `main`।

১. Actions ট্যাব → **Render Bengali Explainer** → **Run workflow** → `main`।
২. ওয়ার্কফ্লো নিজেই টাইপ-চেক → ৬টি প্রিভিউ স্টিল → MP4 রেন্ডার → QC →
   ডেলিভারি ZIP → `render-N` আর্টিফ্যাক্ট আপলোড করে।
৩. শেষে **Artifacts → render-N**-এ পাবেন:
   `final-video.mp4`, প্রিভিউ স্টিল, `QC_REPORT.md`, সম্পূর্ণ ডেলিভারি ZIP।

## সিঙ্ক কীভাবে নিশ্চিত করা হয়েছে

- প্রতিটি দৃশ্যের শুরু আগের কিউয়ের ০.১২ সেকেন্ড আগে; দৃশ্য বদলায় কোনো ফাঁক নেই।
- প্রতিটি অ্যানিমেশন `cueFrame(scene, cueId)` দিয়ে বসানো — অর্থাৎ যে শব্দটি
  বলা হচ্ছে ঠিক সেই কিউয়ের ফ্রেমে টেক্সট/কার্ড/সংখ্যা দেখা যায়।
- SRT বনাম আসল কথার গড় পার্থক্য মাত্র **+০.০২ সেকেন্ড**; ১৯৫টির মধ্যে ১৮৮টি
  কিউ ±০.২৫ সেকেন্ডের মধ্যে।
- SFX ১৬৪টি, প্রতিটি নিজের দৃশ্যের ভেতরে, gain ০.০৯–০.১৭ — ভয়েসের নিচে থাকে।

## গুরুত্বপূর্ণ নিয়ম

- ভয়েসওভার অপরিবর্তিত (`public/audio/voiceover.wav`, মূল কপি `assets/voiceover-new.wav`)।
- SRT শুধু টাইমিং রেফারেন্স — ভিডিওতে সাবটাইটেল নেই।
- আপলোড করা দুই ছবি এই মডেল পড়তে পারেনি; আপাতত ভেক্টর চরিত্র ব্যবহার হয়েছে।
  ছবি `public/images/`-এ এলে চরিত্রের লেয়ার বদলে দেওয়া যাবে।
- SFX সব কোড থেকে তৈরি, কোনো থার্ড-পার্টি অডিও নেই।
