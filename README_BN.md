# বাংলা ফাইন্যান্স এক্সপ্লেনার — সম্পূর্ণ ৮:৫২ (Pay Yourself First)

বাংলা "Pay Yourself First" এক্সপ্লেনারের সম্পূর্ণ Remotion ফিল্ম: **৮ মিনিট
৫২ সেকেন্ড**, ৭৫টি দৃশ্য, ১৯৫টি ন্যারেশন কিউ। ডিজাইনটি অনুমোদিত ৫৯.৩০
সেকেন্ডের `Sample60` স্যাম্পলের ব্রাইট এডিটোরিয়াল স্টাইল অনুসরণ করে: ক্রিম
পেপার, নেভি ইনক, ফ্ল্যাট ভেক্টর ইলাস্ট্রেশন, সবুজ/কোরাল/নীল অ্যাকসেন্ট,
খোলামেলা লেআউট, কিউ-লকড রিভিল এবং হার্ড কাট।

- ফ্রেম: **1920×1080 (16:9)**, **30 fps**, H.264 MP4 + AAC
- দৈর্ঘ্য: **15959 ফ্রেম = 531.96 সেকেন্ড (৮:৫২)**
- ভয়েসওভার: দেওয়া মূল অডিও, অপরিবর্তিত (`public/audio/voiceover.wav`)
- সাবটাইটেল: **বার্ন করা নেই** — `assets/subtitles-new.srt` শুধু টাইমিং রেফারেন্স
- ভিজ্যুয়াল: ১৭টি ব্রাইট টেমপ্লেটে ৭৫টি দৃশ্য; ডাউনলোড ফোল্ডারের দুই
  চরিত্রের আসল ছবি ব্যাকগ্রাউন্ড রিমুভ করে স্টিকার কাটআউট হিসেবে ব্যবহার
  (রাকিব / সুমন); স্ক্রিনের প্রতিটি লাইন, সংখ্যা ও কার্ড ঠিক সেই SRT কিউতে
  আসে যেখানে ভয়েস সেটি বলছে — অর্থাৎ ছবি বাক্য ধরে ধরে ভয়েসের সঙ্গে চলে
- অডিও: মূল ভয়েসওভার + কোড-জেনারেটেড ৮:৫২ স্কোর বেড (`score-full.wav`,
  ভলিউম ০.১২) + ১৬৫টি পরিকল্পিত SFX কিউ — সবই ভয়েসের অনেক নিচে

## GitHub Actions-এ রেন্ডার

রিপো: `s31491771-cell/my-video`, ব্রাঞ্চ `main`।

`render-*` প্যাটার্নের ট্যাগ পুশ করুন (যেমন `render-full-1`) অথবা
**Actions → Render Bengali Explainer → Run workflow** চালু করুন। ওয়ার্কফ্লো:

1. Node, Python, ffmpeg/ffprobe এবং numpy/pillow ইনস্টল করে;
2. `public/audio/score-full.wav` তৈরি করে (৫৩১.৯৬ সেকেন্ড, পিক −৬ dBFS);
3. অ্যাসেট যাচাই করে বাংলা টেক্সট-ফিট অডিট ও ১৯৫ কিউর অডিও-ভিজ্যুয়াল
   সিঙ্ক অডিট চালায় (প্রতিটি কিউয়ে নিজস্ব ভিজ্যুয়াল বিট লাগে, কোনো সংখ্যা
   ভয়েসে বলা হলে সেটি স্ক্রিনে থাকতে হবে);
4. ২৯টি প্রিভিউ স্টিল, তারপর `out/full-video.mp4` (`FullVideo`) রেন্ডার করে;
5. QC (`--expected 531.96 --samples 24`) চালায়, ডেলিভারি ZIP বানায়,
   আর্টিফ্যাক্ট আপলোড করে এবং ট্যাগে রিলিজ তৈরি করে।
