## GitHub Actions-এ রেন্ডার

1. কোড পুশ করুন।
2. **Actions → Render Bengali Explainer → Run workflow** (branch: `main`) চালু করুন।
3. আর্টিফ্যাক্টে `out/sample-60s.mp4`, প্রিভিউ স্টিল, `QC_REPORT.md` এবং ডেলিভারি ZIP পাবেন।

> লোকাল/Termux পরিবেশে Chromium নেই, তাই রেন্ডার GitHub Actions-এ হবে। ফুল ৯ মিনিটের ভিডিও এখন রেন্ডার করা হচ্ছে না; আগে এই স্যাম্পলটি চূড়ান্ত করা হবে।
